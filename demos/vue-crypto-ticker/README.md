# Vue crypto ticker

[DAS-169](https://planetkevin.atlassian.net/browse/DAS-169) composite demo. A page-embed Vue widget assembled from existing `@rosettadash/vue` atoms. Spot prices and 7-day charts come from the public CoinGecko API (no key).

## Run

```bash
npm run demo:crypto
```

Opens [http://localhost:4326](http://localhost:4326).
