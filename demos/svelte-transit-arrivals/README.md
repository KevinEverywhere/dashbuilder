# Svelte transit arrivals

Page-embed Svelte widget assembled from existing `@rosettadash/svelte` atoms. Predictions come from the public [MBTA v3 API](https://api-v3.mbta.com/) (no key). If the request fails, the widget falls back to sample arrivals.

## Run

```bash
nx serve svelte-transit-arrivals
```

Opens [http://localhost:4329](http://localhost:4329).
