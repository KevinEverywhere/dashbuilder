# Web component listing browser

[DAS-169](https://planetkevin.atlassian.net/browse/DAS-169) composite demo. A page-embed vanilla widget assembled from existing `rd-*` atoms. Listings are bundled sample homes in San Francisco, Austin, Lisbon, and Tokyo — up to ten per city, no real-estate API key.

## Run

```bash
npm run demo:listing
```

Opens [http://localhost:4331](http://localhost:4331).
