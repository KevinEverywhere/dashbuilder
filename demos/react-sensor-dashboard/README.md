# React sensor dashboard

[DAS-169](https://planetkevin.atlassian.net/browse/DAS-169) composite demo. A page-embed React widget assembled from existing `@rosettadash/react` atoms. Air quality comes from [Open-Meteo](https://open-meteo.com/) (no key).

## Run

```bash
npm run demo:sensor
```

Opens [http://localhost:4322](http://localhost:4322).
