# Vue flight tracker

[DAS-169](https://planetkevin.atlassian.net/browse/DAS-169) composite demo. A page-embed Vue widget assembled from existing `@rosettadash/vue` atoms. Live aircraft come from OpenSky through the Vite dev proxy (no key). Sample traffic is used if the API is rate-limited.

## Run

```bash
npm run demo:flight
```

Opens [http://localhost:4327](http://localhost:4327).
